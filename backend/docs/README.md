# Documentação da API (Swagger)

- `swagger.json` — descrição de todos os endpoints no formato OpenAPI 3.
- A documentação é mostrada em **`/api-docs`** pelo Swagger UI (ver `app.js`):
  - no teu computador: http://localhost:3000/api-docs
  - no Vercel: https://sir-tp1-backend.vercel.app/api-docs

Em cada endpoint, **Try it out → Execute** faz o pedido à API e mostra a resposta.
